# Jerry

**Голосовой ИИ-ассистент для Windows.**

Умеет выполнять команды (например, установка таймера или открытие приложений). Работает на базе **Ollama**, также интегрирован поиск **ddgs**.

> ⚠️ *Проект находится в стадии активной разработки, поэтому функционал пока ограничен.*

## 🛠 Технологии
*   **База:** Ollama (локальные языковые модели)
*   **Поиск:** ddgs
*   **Платформа:** Windows
*   *Примечание:* Код написан почти полностью с помощью ИИ, человеком озвучены только звуки.
